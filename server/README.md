# Сервер заказов S1 CONTEST

Принимает заказы (VIP-билеты, мастер-классы), создаёт платежи (карта / СБП-QR через ЮKassa),
хранит голоса опроса и анкеты волонтёров. Без зависимостей, нужен Node.js 18+.

## Запуск
```
cd S1-CONTEST
node server/server.js            # сайт + API на http://localhost:3000
```
Без переменных окружения сервер работает в ДЕМО-режиме: заказы сохраняются, но платёж не создаётся.

## Подключение оплаты (ЮKassa)
1. Заключите договор с ЮKassa, получите shopId и секретный ключ; включите способы «Банковские карты» и «СБП», фискализацию (чеки 54-ФЗ).
2. В личном кабинете добавьте HTTP-уведомление `payment.succeeded` на `https://ВАШ-САЙТ/api/yookassa`
   (статус всё равно перепроверяется запросом к API, так что подделать уведомление нельзя).
3. Запуск:
```
YK_SHOP_ID=123456 YK_SECRET=live_xxx SITE_URL=https://ваш-сайт.рф node server/server.js
```
Если вы пользуетесь другим провайдером (Т-Банк, CloudPayments и т. п.) — меняется только функция `ykCreate`/`ykGet`.

## Переменные окружения
| Переменная | Назначение |
|---|---|
| PORT | порт (по умолчанию 3000) |
| SITE_URL | публичный адрес сайта (для возврата с оплаты картой) |
| YK_SHOP_ID, YK_SECRET | ключи ЮKassa |
| TG_BOT_TOKEN, TG_CHAT_ID | уведомления организаторам в Telegram о новых заказах, оплатах и волонтёрах |
| ADMIN_KEY | ключ для просмотра данных: `/admin/orders?key=…`, `/admin/volunteers?key=…`, `/admin/poll?key=…` |
| POLL_SALT | любая случайная строка (для защиты от накрутки опроса) |
| DATA_DIR | где хранить данные (по умолчанию `server/data`) |
| CORS_ORIGIN | если сайт лежит на другом домене (например, GitHub Pages) — его адрес; тогда в `config.js` укажите `apiBase` |

## Важно
- Хостинг — на территории РФ (персональные данные граждан РФ, 152-ФЗ). Папку `server/data` не публиковать и бэкапить.
- Цены и даты акции меняются только в `config.js`; сервер сам пересчитывает сумму и не доверяет цене из браузера.
- Реквизиты организатора в `config.js` → `organizer` подставляются в оферту и политику.
