# Сервер заявок S1 CONTEST

Простой сервер без зависимостей (Node.js 18+). Принимает заявки на участие, записи на мастер-классы и заказы зрительских билетов.
**Онлайн-оплаты нет:** после отправки формы администратор связывается с заявителем и согласует оплату.

    node server/server.js

Переменные окружения:

- `PORT` — порт (по умолчанию 3000)
- `DATA_DIR` — где хранить `orders.json`
- `TG_BOT_TOKEN`, `TG_CHAT_ID` — (необязательно) уведомления администратору в Telegram о каждой заявке
- `ADMIN_KEY` — ключ для просмотра заявок: `/admin/orders?key=…`
- `CORS_ORIGIN` — если сайт и сервер на разных доменах

Сервер нужно размещать на территории РФ (152-ФЗ). Реквизиты организатора и цены — в `config.js`.
